# Strategic Decision-Making System in LLM Agents for FreeCiv

This document explains how the BaseLang and Mastaba agents make strategic decisions in FreeCiv, including the internal mechanisms for game state analysis, decision evaluation, and action selection.

## Game State Understanding

The LLM agents use sophisticated mechanisms to understand and interact with the FreeCiv game environment:

- **Observation Processing**: Transforms raw game data into natural language descriptions
- **Contextual Analysis**: Identifies resources, terrain types, and strategic opportunities
- **Strategic Evaluation**: Rates decisions based on game context and strategic value

def select_fallback_action(dialogue):
    """Selects a valid action when the primary action selection fails."""
    # Extract available actions from dialogue
    available_actions = []
    for msg in reversed(dialogue):
        if msg['role'] == 'user' and 'available action list is' in msg['content']:
            match = re.search(r'available action list is \[(.*?)\]', msg['content'], re.IGNORECASE)
