# Turn Management System in LLM Agents for FreeCiv

This document explains how turn management works in the CivRealm LLM agents, detailing the process that determines when and how the game advances from one turn to the next.

## Turn Structure Overview

In FreeCiv (and CivRealm), the game progresses through a series of turns where each player controls multiple units and cities:

1. **Player receives game state information**
2. **Player decides actions for each unit and city**
3. **Once all units/cities have acted (or been skipped), the turn ends**
4. **Game processes all actions and updates the world state**
5. **Cycle repeats with the next turn**

## How the LLM Agent Handles Turns

The LLM agent doesn't explicitly decide to "end turn" - this process happens automatically when all controllable entities have acted:

```python
                # Once all have acted, the turn automatically advances
```

### Actor Tracking System

The system keeps track of which actors (units and cities) have already performed actions:

```python
# Simplified representation of the actor tracking system
self.acted_units = set()  # Tracks units that have already acted

def get_next_actor(self, actors):
    for actor_id in actors:
        if actor_id not in self.acted_units:
            return actor_id
    # If all actors have acted, return None, triggering turn end
    return None
```

### Game Controller Integration

The underlying game controller (`civ_controller.py`) determines when all units have acted and advances the game:

```python
# In civ_controller.py
def process_turn(self):
    if all_units_have_acted():
        advance_to_next_turn()
    else:
        wait_for_remaining_actions()
```

## LLM Decision Making for Turn Management

### Action Selection Algorithm

For each actionable entity (unit or city), the LLM performs these steps:

1. **Receives current state observation** for that entity
2. **Analyzes available actions**
3. **Selects an action** based on strategic consideration
4. **Executes the action**
5. Entity is marked as "acted" for the current turn

### Action Types Affecting Turn Progression

Several action types affect how turns progress:

- **Standard Actions**: Moving units, building improvements, etc.
- **Keep Activity**: Indicates the unit should continue its current activity
- **Fallback Actions**: Selected when the LLM fails to decide or chooses an invalid action

## Advanced Turn Management

### Priority-Based Actor Selection

The system prioritizes certain actors over others based on strategic importance:

1. **Units that can found cities** (Settlers) are often prioritized
2. **Military units** in dangerous situations receive high priority
3. **Workers** with partially completed improvements are given preference

### Multi-Turn Action Planning

The LLM agent can plan actions that span multiple turns:


## Common Turn Management Patterns

### Early Game Turn Pattern

In the early game, turns typically follow this pattern:
1. **Move Settlers** to optimal city locations
2. **Found cities** in strategic positions
3. **Begin producing** new Settlers or Warriors
4. **Explore** the surrounding territory

### Mid-Game Turn Pattern

As the game progresses, the turn pattern becomes more complex:
1. **Manage multiple cities'** production queues
2. **Direct Workers** to improve tiles
3. **Position military units** defensively or offensively
4. **Research new technologies**
5. **Conduct diplomacy** with other civilizations

### Turn Error Recovery

If errors occur during turn processing, the system can recover:

```python
# Error recovery mechanism
try:
    # Process normal turn actions
except Exception as e:
    fc_logger.error(f"Error processing turn: {str(e)}")
    # Use fallback actions to ensure turn progression
    return select_fallback_action(dialogue)
```

# Sistema de Gestión de Turnos en Agentes LLM para FreeCiv

Este documento explica cómo funciona la gestión de turnos en los agentes LLM de CivRealm, detallando el proceso que determina cuándo y cómo el juego avanza de un turno al siguiente.

## Estructura General de los Turnos

En FreeCiv (y CivRealm), el juego progresa a través de una serie de turnos donde cada jugador controla múltiples unidades y ciudades:

1. **El jugador recibe información** sobre el estado del juego
2. **El jugador decide acciones** para cada unidad y ciudad
3. **Una vez que todas las unidades/ciudades han actuado** (o han sido omitidas), el turno termina
4. **El juego procesa todas las acciones** y actualiza el estado del mundo
5. **El ciclo se repite** con el siguiente turno

## Toma de Decisiones del LLM para la Gestión de Turnos

### Algoritmo de Selección de Acciones

Para cada entidad accionable (unidad o ciudad), el LLM realiza estos pasos:

1. **Recibe la observación** del estado actual para esa entidad
2. **Analiza las acciones disponibles**
3. **Selecciona una acción** basada en consideraciones estratégicas
4. **Ejecuta la acción**
5. La entidad se marca como "actuada" para el turno actual

### Tipos de Acciones que Afectan la Progresión de Turnos

Varios tipos de acciones afectan cómo progresan los turnos:

- **Acciones Estándar**: Mover unidades, construir mejoras, etc.
- **Mantener Actividad** (Keep Activity): Indica que la unidad debe continuar su actividad actual
- **Acciones de Respaldo** (Fallback): Seleccionadas cuando el LLM no puede decidir o elige una acción inválida

### Detección y Prevención de Callejones sin Salida

El sistema incluye mecanismos para detectar cuando un agente está atrapado en un bucle:

## Gestión Avanzada de Turnos

### Selección de Actores Basada en Prioridades

El sistema prioriza ciertos actores sobre otros basándose en la importancia estratégica:

1. **Las unidades que pueden fundar ciudades** (Settlers) suelen tener prioridad
2. **Las unidades militares** en situaciones peligrosas reciben alta prioridad
3. **Los trabajadores** con mejoras parcialmente completadas tienen preferencia

## Patrones Comunes de Gestión de Turnos

### Patrón de Turnos de Inicio de Juego

En el inicio del juego, los turnos típicamente siguen este patrón:
1. **Mover Settlers** a ubicaciones óptimas para ciudades
2. **Fundar ciudades** en posiciones estratégicas
3. **Comenzar a producir** nuevos Settlers o Warriors
4. **Explorar** el territorio circundante

### Patrón de Turnos de Mitad de Juego

A medida que el juego avanza, el patrón de turnos se vuelve más complejo:
1. **Gestionar las colas de producción** de múltiples ciudades
2. **Dirigir a los Workers** para mejorar casillas
3. **Posicionar unidades militares** defensiva u ofensivamente
4. **Investigar nuevas tecnologías**
5. **Realizar diplomacia** con otras civilizaciones
